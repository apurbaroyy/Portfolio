# ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/apurbaroyy/portfolio.git
```

Move into Project

```bash
cd portfolio
```

Install Packages

```bash
npm install
```

Start Development Server

```bash
npm run dev
```

Production Build

```bash
npm run build
```

Preview Build

```bash
npm run preview
```
